FEAT-002 live economic-loop demonstration (real transcript)
============================================================
Captured by running the freshly-built matrixd + matrix binaries against a single
dev node (ACLs disabled) that applied genesis on Start.

Settlement path exercised: market CompleteJob (a direct market.Ledger transfer
buyer -> provider). This is the sanctioned single-dev-node settlement path
(node.go documents that market.CompleteJob's direct ledger.Transfer is retained
for local/single-node use). The consensus-backed path
(node.ComputeSettlementCoordinator) is the multi-node production default and is
covered by internal/node/compute_settlement_test.go; it is not what `matrix job
complete` drives.

Observed balance deltas (native base units, 9 decimals):
  reward pool : 1000000000000000000 -> 999999999999000000  (funded buyer -1,000,000)
  buyer-alice : 0 -> 1,000,000 (funded) -> 999,950 (settled, -50 job price)
  provider-bob: 0 -> 50 (settled, +50 job price)
Job: 10 units @ price 5/unit = 50; buyer down exactly 50, provider up exactly 50.

Commands: matrixd --init (writes default genesis reward_pool), matrixd start,
matrix health, matrix balance, matrix fund, matrix provider register,
matrix job submit, matrix job complete, matrix balance.
